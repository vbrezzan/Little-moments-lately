# Little Moments – Family Album

Aplicativo independente, local-first e offline. Os dados e fotos ficam no aparelho, no IndexedDB `little-moments-family-db`. Não acessa o banco da versão anterior (`little-moments-db`).

Abra pelo endereço HTTPS e use o menu do navegador para instalar na tela inicial. Exporte backups JSON regularmente; o arquivo inclui fotos.
